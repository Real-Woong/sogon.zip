# 과거 자료 보관함

현재 구현과 방향을 결정하는 문서가 아니다. 제품 초안, 완료된 리뷰 요청, 초기 DB 데모,
Figma 입력 자료처럼 다시 참고할 가능성은 있지만 일상적인 개발에서는 읽지 않는 파일을
한곳에 모았다.

현재 기준은 [`../direction/`](../direction/)과 루트 [`SOGONZIP.md`](../../SOGONZIP.md)다.

## 구성

| 폴더 | 내용 |
|---|---|
| `product/` | 초기 제품 아카이브, 긴 과거 프로젝트 컨텍스트, HTML 프로토타입 |
| `recommendation/` | 현재 v2 이전의 추천 v1 설계 |
| `reviews/` | 완료된 방향 리뷰·작업 인계 프롬프트 |
| `design-prompts/` | Figma/디자인 생성에 사용했던 원문 프롬프트 |
| `wireframes/` | 날짜 계획 전환 이전의 와이어프레임 |
| `db-demo/` | 실제 D1 도입 전에 사용한 SQLite 데모 |

아카이브 안의 링크와 명령은 당시 상태를 기록한 것이므로 현재는 동작하지 않을 수 있다.
