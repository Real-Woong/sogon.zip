Create a mobile app UI design for a Korean relationship-based preference archive app called Sogon.zip / 소곤.zip.

## 1. App Name

App name: Sogon.zip  
Korean name: 소곤.zip  
Reading: 소곤집

The name has two meanings:

1. A .zip file of quietly shared whispers
   - Users quietly save their preferences, small secrets, allergies, date styles, gift preferences, and personal feelings as private files.

2. A private little home
   - “zip” sounds like “집” in Korean, meaning home.
   - The app is a private digital home where close people can softly share preferences and memories.

The app should feel trendy, emotional, private, and slightly playful.

---

## 2. Core Concept

Sogon.zip is an app for couples and close friends.

Users create private 소곤파일 that contain preferences or personal stories.  
These files can be used for date/hangout recommendations without revealing the private content.  
On a specific day, anniversary, or chosen time, the owner can confirm and open/unzip the file to the partner or friend.

Core product logic:

- Users save personal preferences as private files.
- Each file has a tag, content, sensitivity level, opening schedule, and recommendation reflection setting.
- Private files can still influence recommendations.
- The partner/friend cannot see the content until the owner confirms opening it.
- Nothing is automatically revealed.
- When a file is opened, the other person can leave a reaction.
- The opened moment is saved in a shared record calendar.

## 3. Target Users

Primary target:

- Korean 10s and 20s users
- Especially users who like trendy archive-style expressions such as:
  - 성수맛집.zip
  - 여행코스.zip
  - 우리추억.zip
  - 생일선물.zip
- Couples who often struggle to choose date courses
- Close friends who share cafe, food, travel, gift, and hangout preferences
- Users who like emotional but practical relationship apps

The app should not feel like a typical dating app.  
It should feel like a private, stylish, soft file archive for close relationships.

---

## 4. Visual Metaphor

The main UI metaphor is:

computer folder + .zip file + locked file + unzip/open interaction + private home archive

Use a soft, modern, slightly retro computer-folder-inspired UI.

Core visual objects:

- Folder cards
- File cards
- .zip badges
- Locked files
- Unzip button
- File explorer style tabs
- Record calendar
- Small message/reaction bubbles

The UI should look like a warm emotional version of a computer file system.

Avoid making it too corporate or too childish.

## 8. Important Product Rules to Reflect in UI

1. Every preference/story is a 소곤파일.
2. Each 소곤파일 has:
   - file name
   - tag
   - content
   - sensitivity
   - opening timing
   - recommendation reflection ON/OFF
3. A private file can still be reflected in recommendations.
4. The partner/friend cannot see the content until the owner confirms opening.
5. Nothing is automatically revealed.
6. Opening day sends confirmation to the owner first.
7. Once opened, the receiver can leave a reaction.
8. Opened moments are saved in 기록.zip.
9. The app supports both lover mode and friend mode.
10. UI should feel like a soft file archive, not a normal dating app.
